# Booki

## English

This project is part of the [OpenClassrooms](https://openclassrooms.com) curriculum. The goal is to integrate a web interface from mockups using HTML and CSS.

**Booki** is a fictional travel agency website where users can find accommodations and activities in the city of their choice.

## Français

Ce projet fait partie du parcours de formation [OpenClassrooms](https://openclassrooms.com). L'objectif est d'intégrer une interface web à partir de maquettes en utilisant HTML et CSS.

**Booki** est un site fictif d'agence de voyage permettant aux utilisateurs de trouver des hébergements et des activités dans la ville de leur choix.
